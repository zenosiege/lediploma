# 4. Разделение узлов
- sun_compass_camera_noise - инициализация камеры для получения ряда изображений с заданной скоростью в к/c *(автор: Пантилеев Данила Юрьевич)*;
- shadow_filter - сегментация изображения для упрощения задачи определения угла азимута *(автор: Пантилеев Данила Юрьевич)*;
- sun_shadow_detection - извлечение угла тени от стержня относительно локального нуля, и определение угла азимута в соответствии с датой и временем суток *(автор: Максев Алексей Олегович)*.

# 6. Логика сборки проекта
Сборка происходит посредством команды ***colcon build*** (или нажатием сочетания Ctrl+B в окне Qt Creator).

Запуск нод осуществляется в несколько этапов:
1. После сборки в папке проекта необходимо выполнить команду "source install/setup.bash" для установки программы.
2. Запустить sun_compass_hough через команду "ros2 run sun_compass_camera_noise sun_compass_camera_noise_node".
3. Запустить sun_shadow_detection через команду "ros2 run sun_shadow_detection sun_shadow_detection_node".

Чтобы наблюдать выполнение программы, рекомендуется открыть rviz2, выполнив "rviz2" в терминале.
В открывшемся окне программы в левой нижней части нажать кнопку Add и во вкладке By Topic найти топик /image_processed, и под ним выбрать Image.
